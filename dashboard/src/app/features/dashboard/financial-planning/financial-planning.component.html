How this planner works

Model income, spending, portfolio mix, retirement, and life goals (education, marriage, etc.). Monthly income lines can use an earning cap (e.g. a job for only the first N years). Monthly expenses can end after N plan years (0 = no end). Add multiple rental streams with start year and +%/yr (on top of inflation). Green fields mirror typical spreadsheet inputs.
